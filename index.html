🎨 CSS Font Properties

Learn about font-size, font-style, font-family, and font-weight

📏 Font Size

The font-size property controls how big or small your text appears. You can use different units like pixels (px), em, rem, or percentages.

font-size: 16px; /* Absolute size */ font-size: 1.2em; /* Relative to parent */ font-size: 1.5rem; /* Relative to root */ font-size: 120%; /* Percentage */

✏️ Font Style

The font-style property controls whether text is displayed in a normal, italic, or oblique style.

font-style: normal; /* Default style */ font-style: italic; /* Slanted text */ font-style: oblique; /* Similar to italic */

🔤 Font Family

The font-family property specifies the font for an element. You can list multiple fonts as fallbacks.

font-family: Arial, sans-serif; font-family: 'Times New Roman', serif; font-family: 'Courier New', monospace;

⚖️ Font Weight

The font-weight property sets how thick or thin characters in text should be displayed.
